# 圖示人工校正（icon_overrides）

morris 拆包對少數道具的圖檔「檔名對、內容錯」（例如玫瑰椅拿到紅沙發圖、
蘑菇友情椅子拿到玫瑰椅的王座圖、一整段任務道具圖錯位），他自己的網站也
一樣錯，同步上游修不了。這裡放**確認過**的正確圖，`import_db.py` 會在
所有圖片複製完之後把這個資料夾蓋回 `assets/db/`，所以重跑匯入不會把修正
洗掉。

- 目錄結構：`<類別>/<id>.png`（類別對應 assets/db/ 底下的資料夾名）
- 正確圖來源：maplestory.io（WZ 直出）。**經典年代就有的道具用 GMS v62
  的圖**（忠於經典版畫風；v253 有些圖後來重繪過，例如詛咒針、紅十字盾牌
  ——那兩個我們原本的圖才是對的，不要「修」它們）；經典版沒有的新內容
  （轉蛋椅子）用 GMS v253。
- 2026-08-22 建立，首批 14 張，比對方法與完整清單見當日 commit 訊息。
  懷疑有新的錯圖時，可以用 scratchpad 的 icon_audit.py 方法重掃：抓
  maplestory.io 同 ID 圖示，裁透明邊後縮 24×24 比「形狀 IoU＋色差」。
