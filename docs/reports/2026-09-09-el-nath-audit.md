# 網站健檢報告：三轉與冰原雪域

核對日期：2026-09-09。範圍為本次三轉／雪域資料擴充、關聯導覽與 UI/UX，以及既有功能回歸。標記：`verified-live` 為實際命令／瀏覽器／線上服務驗證；`code-inference` 為程式或來源對照；`unchecked` 為無法在此環境確認。

## 這次優先處理的項目

1. **區分現行與預覽**：`data/db/` 不變，新區獨立於 `data/preview/el-nath/`。首頁、資料庫、職業、任務、BOSS 攻略與攻擊計算入口說明狀態。預覽怪物不送入現行練等／推薦地點，也不寫入玩家的計算偏好。
2. **資料缺漏不當成零**：缺少重生點、地形和 NPC 座標時顯示「待確認」。怪物圖鑑關聯不是重生數量，世界地圖連結不是已驗證交通動線。
3. **三轉逐級數值可讀**：整合 12 條冒險家路線、89 個三轉技能、2,330 個技能等級；以來源逐級原文顯示，不在前端猜公式。技能欄名依技能 ID＋名稱判別，避免神聖祈禱等技能誤用鬥氣標籤。
4. **手機導覽與長內容**：世界區域按鈕換行、觸控高度 44px，新增可展開的區域地圖連結清單；攻略章節與職業可折疊，長表格局部橫捲並支援鍵盤聚焦。
5. **來源與非同期內容**：三轉／雪域一般任務目前缺少可用原始明細，不以舊版流程補造；排除僅限未收錄任務的掉落，保留其他版本補充關聯的來源。
6. **切換時不顯示過期資料**：詳情與搜尋加上請求版本檢查，快速切換或清空搜尋後，較晚完成的舊回應不得覆蓋目前畫面。

## Firebase

- `verified-live`：Firestore `(default)` 位於 `asia-east1`；現行 `ts desc`＋游標分頁查詢不需要複合索引。
- `verified-live`：部署中的規則與本機一致；App Check 為 ENFORCED。正式站社群回報功能開放，與 `SUBMISSIONS_OPEN` 一致。
- `unchecked`：未為健檢提交、投票或刪除真實玩家紀錄，亦未更動規則或開放狀態。
- `code-inference`：匿名社群的公開讀取、投票及刪除權限仍有既有成本／濫用風險；本次資料預覽無須擴大權限，也沒有新增 Firestore 查詢。

- `verified-live`（壓縮部署版）：現行怪物 71 種、預覽新增篩選 74 種；「任務攻略 → 社群資料 → 實用情報」能直接切換。未發現新資料庫渲染錯誤；稍後紀錄出現 localhost 的 reCAPTCHA／App Check 錯誤及 Firestore 連線逾時，不據此認定正式站社群故障，亦未繞過驗證。
- 資料庫每頁顯示目前模式；預覽模式包含現行關聯資料並可切換「只看拆包預覽」，不能把所有列都理解為新加入。

- 保留社群職業選單原有儲存值，僅更新顯示名稱，不使歷史紀錄或 Firestore 白名單失效。
